## 🛟 안전장치의 한계

`aa685e4` 의 안전장치(자동 저장·비정상 종료 복구·저장 이력·오류 기록. 동작은 [해결 기록 G](resolved_issues.md#-g-안전장치))로도 막지 못하는 자리입니다.

* 자동 저장 간격이 2분이라, 강제 종료처럼 비상 저장할 틈이 없으면 **마지막 2분 안의 편집은 잃을 수 있습니다.**
* UI 스레드 밖(백그라운드 스레드)에서 난 예외는 기록만 남고 앱을 살리지 못합니다. 이런 경우도 마지막 자동 저장본으로 복구됩니다.
* 이력 스냅숏을 고르는 화면은 없습니다. 원하는 `.bms` 를 **곡 폴더에 복사해 넣고** 이름을 바꿔 열면 됩니다. `#WAV` 경로가 원래 곡 폴더 기준으로 적혀 있어 그대로 열립니다.
* 제목 없는(한 번도 저장 안 한) 문서도 자동 저장·복구하지만, 되살린 뒤 [저장]하면 저장 위치를 새로 묻습니다.
